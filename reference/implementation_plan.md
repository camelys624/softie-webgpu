# 游戏化萌系「打工怨气值」WebGL / WebGPU 怒气条重构方案

根据您的需求，我们将针对情绪状态机与表情演化这部分进行全面升级重构：将原先简单的文字药丸标签，升维改造成**高质感、游戏化、且极富软萌治愈趣味的 WebGL / WebGPU 专属「打工怨气条」（Rage Meter）**。

进度条的展示本身作为核心卖点，具备**物理双层流体波浪晃动、碳酸/岩浆沸腾气泡、温度光晕渐变、受击果冻弹性形变（Juice）、以及 100% 满槽「怨气爆表」爆裂特效**。

---

## 核心设计与卖点架构

### 1. 怒气条外观与主题风格（Kawaii Game HUD）
- **造型设计**：半透明圆润果冻玻璃胶囊管体（Candy Glass Capsule），搭配高光倒角与软糖质感包边，中央为动态流体槽。
- **左侧萌系微表情指示器（Mini Slime Face）**：
  - 随着怒气提升实时演变：
    - `0%~30%` 放空微笑（`^‿^`）；
    - `31%~70%` 撇嘴抽搐（`>_<`）；
    - `71%~99%` 倒八字圆睁（`皿`）；
    - `100% MAX` 豆豆眼喷火 / 冒烟（`💢`）；
    - `打盹休眠` 闭眼安详打呼（`zZ`）。
- **右侧动态数值与段位徽章**：
  - 显示百分比（`0%` ~ `100%`）与段位小标（`摸鱼中` / `微烦` / `忍无可忍` / `MAX 爆表!`）。

### 2. WebGL / WebGPU 精美流体着色器（核心卖点）
- **双层物理流体波浪（Dual-Layer Waves）**：
  - 前景主波浪 + 背景深色波浪，具有自然相位差与黏稠阻尼；
  - **交互惯性晃荡（Inertia Sloshing）**：当戳击或抓甩史莱姆时，怒气条中的流体产生左右惯性倾斜与冲刷动量！
- **自适应温度梯度色彩流变**：
  - 🟢 **0%~30% 佛系摸鱼（Chill）**：温柔抹茶淡粉 / 蜜桃果冻流体，波光微漾，慢悠悠浮起细小碳酸光泡；
  - 🟡 **31%~70% 微烦预警（Annoyed）**：元气柠檬黄 $\to$ 暖橙色汽水，气泡加速生成，流体表面小幅激荡；
  - 🔴 **71%~99% 暴怒升温（Rage）**：高饱和猩红熔岩浆，沸腾剧烈，自发光微光向外扩散；
  - 💥 **100% MAX 怨气爆表（OVERHEAT BURST）**：
    - 炽白热核电浆波浪！
    - 进度条外沿剧烈抖动震颤（Bar Jitter & Screen Shake）；
    - 溢出跳跃的金色能量电火花与火焰微粒；
    - 文字高频闪耀「MAX! 💢 怨气爆表」；
  - 🔵 **休眠打盹（Sleepy Mode）**：当史莱姆无交互 8.5 秒睡着时，进度条缓缓变为半透明梦幻夜空蓝，液面轻柔起伏如呼吸。
- **打击受击反馈（Hit Juice & Spring Physics）**：
  - 每次戳击（Poke）不仅怒气暴涨，整根怒气条还会发生类似软糖的果冻受击挤压形变（Squash & Stretch），液面产生向上的激凸冲击波与白光闪烁（Hit Flash）。

## 提议的变更与实现步骤

### 1. 新增 WebGL/WebGPU 进度条渲染引擎：`src/rage-meter.js`
- 封装独立的高性能 `RageMeter` 类；
- 采用 GLSL 自定义着色器（支持全平台 WebGL 2.0 / WebGL 1 高效渲染，与现有 WebGPU 主画布无缝协同，避免多 WebGPU Device 上下文冲突限制）；
- 实现数学 SDF 圆角胶囊外框、多重波浪合成、碳酸气泡粒子池、弹簧阻尼物理形变。

### 2. 界面与布局重构：`index.html` & `src/style.css`
- 将 stage 上方原先静态的 text badge 重构升级为位于舞台顶部中央（或显要焦点区）的 **游戏化 HUD 怒气槽容器**：
  ```html
  <div id="rage-meter-container" class="rage-meter-hud" aria-label="打工怨气值">
    <!-- WebGL Canvas + 萌系头像 + 百分比徽标 -->
  </div>
  ```
- 适配桌面端（约 340px 宽度）与移动端响应式布局，保证居中且不遮挡史莱姆拖拽区域。

### 3. 情绪状态机与主循环联动：`src/face-motion.js` & `src/main.js`
- `face-motion.js`：怒气值（`0.0 ~ 1.0`）平滑过渡输出，增加受击瞬态增量；
- `main.js`：
  - 在帧循环中把 `slime.faceMotion.anger`、情绪状态、睡眠状态实时送入 `rageMeter.update(dt, anger, mood, isSleeping)`；
  - 戳击时触发 `rageMeter.pulse()` 赋予受击回弹果冻动量。

### 4. 多语言国际化与无障碍支持：`src/i18n.js`
- 新增中英双语标签：
  - `rageMeterTitle`: `打工怨气槽` / `Fury Gauge`
  - `rageChill`: `摸鱼蓄力` / `Chill`
  - `rageAnnoyed`: `有点上火` / `Simmering`
  - `rageMax`: `MAX 怨气爆表!` / `MAX RAGE!`
  - `rageSleepy`: `呼噜补能中` / `Napping…`
