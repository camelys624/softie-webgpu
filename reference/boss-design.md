# 甩锅蟹总：已确认的 A 方案

概念图：`boss-approved-concept.png`。以 A「背手训话」为基础；B、C 的压价和改需求用于同一个角色的台词，不叠加眼镜、钱袋和大需求板。

## 角色

装腔作势的小领导，对外包缺乏尊重：贬低工作成果、把新增工作算进原费用、反复改需求，最后把责任推给执行者。主要笑点是“装得很有把握，挨敲后瞬间心虚”。

## 造型约束

- 使用原版果冻身体、顶端小尖、透明材质、内部气泡和现有颜色。
- 使用原版小黑眼睛的位置和比例，半垂上眼皮、一高一低的眉毛、略微歪斜的小笑；取消早期方案的白色大竖眼。
- 紫色高腰裤、细腰带、小金扣、口袋和裤袢。小红脚，迷你蟹钳背在身后。
- 手势、眉毛、裤子跟随原版软体变形场；锤击只产生轻微回弹。
- 原有用户配件和设置不被附身覆盖。

## 动作和计时

1. 登场背手，随后短暂伸出一只钳子指点。
2. 首次命中：笑容僵住、眼睛短暂睁圆，台词“哎？我还没说完呢！”。
3. 一两次命中：眉毛落下，尝试嘴硬，“我只是要求高一点嘛……” 。
4. 连续命中或开始心虚后：圆眼、小圆嘴、两钳护头、小金扣歪斜；改口承认对应的问题。
5. 最后 900 毫秒按照净化星锤设计图右下角「附身解除」分镜：裤子、腰带和蟹钳组成完整装扮，顺时针倾斜，一起抛向右上方。粉紫色花瓣状烟团包住装扮，下方拖出两条卷曲、尖尾的烟带，点缀少量金色星星。眉毛和红脚消失，原版果冻原地露出闭眼弧线笑，侧上方出现金色小短线。锤子、命中光环和台词气泡在抛出时收起。后半段约 450 毫秒，装扮和烟团继续向右上方轻飘、缩小，同时逐渐透明；烟尾和星屑收向烟团，直至尺寸和透明度归零，不保留静止停顿。

首次命中起 **5000 毫秒**退出，后续命中不延长；完全不打则登场 **10000 毫秒**后退出。3–5 分钟随机冷却，首次登场和每次退场后都重新计时，揉捏期间推迟登场。主动召唤不受冷却限制，不重置正在进行的事件。

受击时只从落点散出 3 颗小星星，沿平滑弧线向上飘散、减速并缩小渐隐；移除额外头顶星星和光圈星星。连续挥锤时星星簇至少间隔 380 毫秒、最多同时两簇，旧星星自然消失。锤子从当前姿态继续挥动并柔和回弹，减少连击中的姿态跳变。

## 台词对应

文案池集中配置在 `src/boss-dialogue.js`：共 16 组，分为贬低成果、抠门压价、反复改需求、装腔指挥，每类 4 组。每组包含中英文训话和对应改口。每次登场随机抽取，避开上一次的台词；同一次附身保持同一组，语言切换和挨打都不重新抽取。后续添加配置项即可自动加入抽选。下表保留最初四组作为示例。

| 训话 | 改口 |
| --- | --- |
| 做了这么久，就这些？ | 是我没认真看，你这版做得不错。 |
| 这个应该算在原来的费用里。 | 新增的工作，费用另算！ |
| 还是第一版好，你怎么没坚持？ | 这版就定了，不改了！ |
| 这也需要我教？ | 是我没说清楚，我把需求写好。 |

## 已确认的 A「净化星锤」

参考图：`hammer-approved-concept.png`，采用左侧 A。奶油粉软锤头、金色星星封印、奶油色小翅膀、浅紫魔杖柄、螺旋握带与粉色尾珠。

实际使用可缩放的 SVG。桌宠窗口锤子宽 88–100 像素，网页根据窗口宽度为 100–180 像素；相较原来的 60 像素增大。悬停优先位于表情侧上方，同时避开气泡及窗口边界。挥锤才短暂移至命中点。

命中产生轻薄的金紫净化环与星屑，音效为低音软锤声叠加两个轻铃音。退场采用右下角分镜的装扮抛出、粉紫烟团和闭眼笑，不再用原地淡出来代替。减少动态效果下关闭挥锤和净化环，保留静态星锤及计时；静音沿用已有设置。

## 交互兼容

气泡采用一句话对话：老板只显示内容，不显示标题、操作提示、命中次数和计时条，颜色保持奶油黄。心情变化时显示粉紫色心情气泡，约 4 秒后淡出；期间再次变心情就换成新回应，语言切换不延长显示时间。附身时隐藏心情气泡，退场后再回应。同一时间只显示一个气泡，避开表情、拖动把手与悬停锤子。减少动态效果时静态显示、到时隐藏。

心情文案采用「打工搭子」口吻：沮丧时「怎么又不算数了…」，安慰时「还好，你懂我。」，恢复后「他说的不算，我做得很好。」停留 3.5 秒，再回到平常的闲置文案。英文同步表达同样的情绪。

成功打退老板会清空此前累计的沮丧、安慰进度和怨气，明确进入约 6 秒的开心心情，延续退散时的笑容，文案「终于清净了，摸会儿鱼。」最后一秒笑容自然收回；取消附身或重置不触发胜利庆祝。

未反击的老板离开后进入沮丧：耷拉的眼睛、下弯的小嘴，退散预览不再闭眼庆祝。戳一下后逐渐恢复；首次 1.2 秒，恢复前每次未反击追加 2 秒，上限 9.2 秒。再次戳戳不重置安慰进度、不增加怨气。恢复期间再次附身会暂停安慰，未反击离开则累加并等待下一次安慰。完全恢复或恢复默认会清空累计。页面隐藏、取消或重置附身不计为未反击。

鼠标、触摸、空格和按住连敲；失焦、指针取消、切换页面时释放连敲。减少动态效果时保留表情阶段及计时，关闭指点循环、抖动、挥锤、星星和装扮飞散，只淡出。音效遵循已有静音和音量设置。
